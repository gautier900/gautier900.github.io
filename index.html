Piste 01 · Notes de pochette

À propos

Je m'appelle Gautier, je suis en 3e année de BUT Informatique à l'IUT Nord Franche-Comté, à Belfort. Je me spécialise dans le développement full stack, avec un faible pour la conception d'API.

Ce qui me plaît, c'est un problème concret à résoudre : faire jouer une intelligence artificielle, faire circuler les données d'une boutique entre le serveur et l'interface, ou automatiser des tests pour qu'une application reste fiable.

En dehors du code, je fais de la musculation, je regarde beaucoup de thrillers et de films à énigme, et j'écoute énormément de rap, d'où ce site en forme de playlist. Les pochettes qui défilent sur l'accueil ? Ce sont mes vrais albums du moment.

Veille informatique

Les trois sujets que je suis de près, ce que j'en retiens, et où je les lis.

Ép.1

Épisode 01 · IA & développement

Coder avec un assistant IA

Les assistants comme Claude Code ou GitHub Copilot écrivent maintenant des fonctions entières. Ce que j'en retiens : relire et tester ce code compte plus que jamais. C'est justement ce que j'ai fait pendant mon stage en automatisant des tests.

Ép.2

Épisode 02 · Web

Ce que les navigateurs savent faire seuls

Le CSS gère désormais des effets qui demandaient du JavaScript : sélecteur :has(), requêtes de conteneur, transitions entre les vues. Côté 3D, WebGPU arrive dans tous les navigateurs, une piste pour les planètes d'UnderSpace.

Ép.3

Épisode 03 · Sécurité

Les failles les plus courantes des API

D'après l'OWASP, la faille n°1 des API, c'est d'oublier de vérifier que l'objet demandé appartient bien à l'utilisateur. Ce que j'en retiens pour mes prochaines API : vérifier les droits à chaque requête, et pas seulement à la connexion.
